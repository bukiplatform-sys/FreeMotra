Uygulama içi güncelleme desteği / In-app updates

- Yeni sürümler açılıştan sonra ve altı saatte bir kontrol edilir.
- Güncelleme kartında sürüm notları, indirme ilerlemesi ve iptal bulunur.
- Dosya boyutu ve SHA-256 doğrulanır; kurulumdan önce tekrar kontrol edilir.
- Kurulum açık onay ister; aktif veya bekleyen oturum varken başlatılmaz.
- Yönetim panelinden yayınlanan reklamlar otomatik yenilenmeye devam eder.

New versions are checked automatically. Downloads are verified, and the
Windows installer starts only after your confirmation with no active session.

Bağlantı bu sürümde aynı yerel ağ (LAN) içindir. İnternet bağlantısı henüz yoktur.
Remote sessions currently require the same local network (LAN).
