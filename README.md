# FreeMotra
C++20, Qt6/QML, CMake Windows x64 geliştirme sürümü.
Uzak bağlantı henüz hazır değildir. Bağlan düğmesi bu durumu açıkça belirtir.
Actions başarılı olduğunda artifact içindeki ZIP'in tamamını çıkarın; DLL'leri EXE'den ayırmayın.
Dil, tema ve tercihler Windows kullanıcısı için kaydedilir. Şifre diske yazılmaz.
Dağıtımdan önce NOTICE.md lisans gerekliliklerini tamamlayın.
